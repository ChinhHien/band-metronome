Chọn một bài hát đã soạn để tiếp tục, hoặc tạo bài hát mới:

    Chưa có bài hát nào — bấm “Tạo bài hát mới” để bắt đầu.

    Tạo bài hát mới

    Hãy đặt tên cho bài hát.

    Dán cấu trúc bài dạng JSON. Chỉ sections là bắt buộc; title, base và các mục count_* có thể bỏ trống.

    {
  "title": "Tên bài",
  "base": { "bpm": 120, "time_signature": "4/4", "sample_rate": 48000 },
  "sections": [
    { "name": "Intro",  "bpm": 120, "bars": 4, "time_signature": "4/4",
      "count_in": true, "count_out": true, "read_marker": true },
    { "name": "Chorus", "bpm": 120, "bars": 8 }
  ]
}
    • sections — 1 đến 100 đoạn.
    • bpm — số, 20 đến 400.
    • bars — số nguyên, 1 đến 128.
    • name — tối đa 60 ký tự.
    • time_signature — 2/4 3/4 4/4 5/4 6/8 7/8 9/8 12/8 (bỏ trống thì lấy theo base, nếu không có nữa thì 4/4).
    • count_in count_out read_marker — true/false (mặc định chỉ read_marker là true).
